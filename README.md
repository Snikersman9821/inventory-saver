# Inventory Saver

A simple Fabric mod for Minecraft that lets you save and restore your inventory using keybinds. Handy for hard modded playthroughs, testing, or just keeping a backup of your gear.

## Features
- Save and load inventory
- Profiles to save different inv states
- Save of profiles for each world and server
- Config screen built with a visual preview
- Adjustable click-per-tick limit so it doesn't get flagged by anti-cheat plugins on servers

## Default Keybinds
- **K** - Save inventory
- **L** - Restore inventory
- **J** - Open config screen

## Building from Source

### Build Requirements
- **Java Development Kit (JDK):** Version 25 (configured via toolchain in `build.gradle`)
- **Gradle:** Version 9.8.2 (bundled via wrapper)
