# Inventory Saver

A simple Fabric mod for Minecraft that lets you save and restore your inventory using keybinds. Nice if you died and need to sort your inventory quickly.
## Features
- Save and load inventory
- Profiles to save different inv states
- Save of profiles for each world and server
- Config screen built with a visual preview
- Adjustable click-per-tick limit so it doesn't get flagged by anti-cheat plugins on servers

## Default Keybinds
- **K** - Save inventory
- **L** - Restore inventory
- **J** - Open config screen

## Building from Source

### Build Requirements
- **Java Development Kit (JDK):** Version 25
- **Gradle:** Version 9.8.2
